# SurveyQuant Website | مكتب فني مساحة

هذه حزمة موقع تعريفي تجاري باللغة العربية لتطبيق **SurveyQuant / مكتب فني مساحة**، متوافقة مع عرض الهاتف.

## محتويات الحزمة
- `index.html`: الصفحة كاملة، وتشمل الشعار والصورة التعريفية مضمنين داخل الملف؛ لا تحتاج إلى رفع ملفات صور منفصلة.
- أسعار الاشتراك حسب ما حدده صاحب التطبيق:
  - شهري: 55 جنيهًا مصريًا.
  - 3 شهور: 150 جنيهًا مصريًا.
  - سنوي: 500 جنيه مصري.
  - لا توجد خطة تفعيل دائم حاليًا.
- وصف أدوات ومشروعات التطبيق، وروابط تنزيل APK المنشور حاليًا `v1.0.91`.
- أقسام أولية لسياسة الخصوصية والشروط والأحكام.

## النشر من هاتف أندرويد
1. نزّل ملف ZIP وافتحه من تطبيق «الملفات» على الهاتف.
2. افتح: https://github.com/new
3. أنشئ مستودعًا جديدًا بالاسم `surveyquant-website` واختر `Public`، ثم أنشئ المستودع.
4. افتح المستودع الجديد، ثم `Add file` ثم `Upload files`.
5. ارفع الملفين الموجودين داخل الحزمة: `index.html` و`README.md`، ثم اضغط `Commit changes`.
6. افتح `Settings` ثم `Pages`.
7. في `Build and deployment` اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/(root)`، واضغط `Save`.
8. انتظر ظهور رابط النشر في صفحة Pages. سيكون عادةً:
   `https://aboabdalla72229-hash.github.io/surveyquant-website/`

## قبل إرسال الرابط إلى كاشير
- أضف وسيلة التواصل الرسمية الخاصة بالنشاط (صفحة فيسبوك أو واتساب أعمال أو بريد دعم)؛ لم يتم اختراع بيانات تواصل غير مزودة.
- تأكد أن كاشير يقبل GitHub Pages، أو اسأله إن كان يشترط دومينًا خاصًا.
- الصفحة **لا تستقبل مدفوعات ولا تجمع بيانات بطاقات حاليًا**، ولا تدّعي أن بوابة كاشير مفعلة. لا بد من إضافة وربط تكامل الدفع بعد موافقة كاشير.
- راجع سياسة الاسترداد والإلغاء وبيانات النشاط وحدث صفحات الشروط والخصوصية بما يطابق طريقة عمل التطبيق الحقيقية قبل مراجعة التاجر النهائية.
- رابط تنزيل APK في الصفحة يشير إلى الإصدار المنشور `v1.0.91`؛ حدّثه عند نشر إصدار أحدث إذا تغيرت طريقة رابط التنزيل.
